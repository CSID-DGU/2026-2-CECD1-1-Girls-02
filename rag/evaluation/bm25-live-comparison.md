# Chroma 실데이터 BM25 Basic·Kiwi 비교

## 데이터와 평가 질문

루트 `.env`에서 지정한 원격 Chroma의 `brand_a_official_knowledge`를 읽기 전용으로 조회했다. 전체 112개 청크가 공식·활성·승인·`DRAFT_ONLY` 조건을 충족했고, 고유 문서 ID는 103개였다. 청크 ID의 유일성과 `document_id`, `source_id`, `document_version`, `title`의 존재를 확인했다.

`OfficialChromaChunkLoader`로 한 번 읽은 스냅샷을 두 `BM25IndexManager.rebuild()` 호출에 공급했다. Basic과 Kiwi 모두 `ready`였고 청크 ID 및 순서 검증을 통과했다. 두 인덱스 모두 112개 청크와 동일한 스냅샷 ID `f3eaff97bd8fb2c2fbf04ffcda42215ce83b7f062714ca9449833cb92989e2ea`를 사용했다.

기존 GT 예시는 샘플이고, 로컬 수동 평가 템플릿 25행에는 질문이 없으며 모두 검수 대기 상태였다. 템플릿의 출처 후보를 우선 사용해 기업 FAQ의 활성 원문 질문 25개를 선정했다. 각 원문의 출처 ID를 Chroma의 승인된 FAQ 메타데이터에 매핑했고, 고유 문서 ID 하나로 매핑되는 사례를 사용했다.

자동 변형 44개는 별도로 평가했다. 기존 변형 또는 동일 어미 변환 규칙으로 만든 어미 변형 11개, 규칙 기반 표현 치환 8개, 원문의 긴 표면 단어를 최대 세 개 남긴 짧은 키워드 질의 25개다. 문서 ID는 변형의 출처를 가리키는 후보 라벨이다. 원문은 인덱싱된 문구와 겹칠 수 있고, 키워드 질의도 원문 표면형을 유지하며, 변형 질문의 의미 보존과 대체 정답은 사람 검수 대기 상태다. 아래 수치는 실제 BM25 순위로 계산한 탐색 지표다. 이전 토큰 겹침 분석은 질의와 문서의 공통 토큰을 측정했다.

## 평가 방식

같은 질의와 공식 필터로 검색기별 최대 50개 청크를 요청했다. 반환 순서에서 같은 문서 ID는 첫 등장만 남기고 문서 순위의 상위 1·3·5·10개를 평가했다. 반환된 결과가 부족하면 빈 순위를 다른 청크로 채우지 않았다. MRR은 상위 10개에서 첫 정답의 역순위를 평균했다. nDCG@5와 p95는 기존 평가 모듈을 재사용했다. 평균과 p95는 워밍업 이후 토큰화와 점수 계산을 포함한 인메모리 검색 시간이며, Chroma 로딩과 인덱스 생성은 제외한다.

HitRate@K는 상위 K개 안에 정답이 하나라도 있는 질의의 비율이다. Recall@K는 질의마다 찾아낸 고유 정답 수를 전체 정답 수로 나눈 뒤 평균한다. 이번 후보 라벨은 질의당 하나이므로 두 지표의 값이 같다. 기존 모듈의 `recall_at_5`는 HitRate@5 방식이고, 아래 Recall은 실험 스크립트에서 계산했다.

## 추가 비교 · BGE-M3 Dense와 Dense + Kiwi RRF

같은 69개 질문과 동일한 공식 청크 스냅샷에서 기존 Dense 검색기와 HybridRetriever를 실행했다. BGE-M3는 동일 모델의 로컬 캐시를 사용했다. Hybrid는 RRF 상수 60을 유지했고, 문서 중복 제거 전 청크 50개를 확보하도록 최종 요청을 50으로 설정해 두 하위 검색기 각각 최대 50개 후보를 사용했다. 검색 시간에는 로컬 임베딩과 원격 Chroma 왕복이 포함된다.

| 그룹 | 전략 | HitRate / Recall@1 | @3 | @5 | @10 | MRR@10 | nDCG@5 | 평균 / p95 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| FAQ 원문 | Dense | 92.0% | 100% | 100% | 100% | 0.960 | 0.970 | 211.4 / 458.5 ms |

자동 변형에서 RRF는 Dense 대비 Top-5 적중을 40건에서 42건으로 늘렸다. Basic은 동일한 44개 변형에서 44건을 적중했다. Dense와 Hybrid는 순차 실행했고 원격 요청 시간도 포함되므로, 지연시간 차이는 운영 성능 판단 전에 반복 측정이 필요하다.

## 판단과 다음 평가

이번 스냅샷의 BM25 비교 기준선으로 Basic을 우선 추천한다. 두 질의 그룹에서 상위 순위 적중률이 높았고 검색 시간도 짧았다. 결과를 일반화하려면 원문과 별도로 사람이 작성한 자연어 질문을 확보하고, 대체 정답·다중 정답·근거 없음 사례를 검수해야 한다. 특히 짧은 질문에서 순위가 갈린 사례와 실제 고객 표현에서 조사·어미가 달라지는 사례를 포함해 다시 비교할 필요가 있다.
