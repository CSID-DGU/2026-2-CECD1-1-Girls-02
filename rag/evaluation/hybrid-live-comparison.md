# Chroma 실데이터 Dense·RRF Hybrid 비교

## 환경과 평가 데이터

이전 BM25 실험의 비공개 질문별 파일에서 질문 텍스트와 후보 문서 ID를 그대로 읽었다. 원문 25개, 자동 변형 44개(어미 변경 11개, 표현 치환 8개, 키워드 질의 25개)다. 후보 문서 ID는 질문당 하나이며 사람이 정답 범위와 의미 보존을 최종 검수하기 전이다. 원문과 자동 변형은 구분해 평가했다. [이전 BM25 실험](bm25-live-comparison.md)

Apple Silicon macOS에서 Python 3.14와 로컬 BGE-M3 모델 캐시를 사용했다. Chroma 접속 정보는 저장소의 `.env`에서 읽었다. 공식 컬렉션을 조회할 때 사용한 데이터와 실험 중 변경 여부는 아래 실행 결과에 기록했다.

## 검색·측정 조건

- Dense는 `OfficialKnowledgeSearchService`에서 BGE-M3 임베딩과 원격 Chroma 벡터 검색을 실행했다.
- Hybrid 두 방식에 같은 Dense 검색기를 연결했다. BM25 토크나이저만 Basic 또는 Kiwi로 바꿨고, `HybridRetriever`의 동일 가중치 RRF 상수는 60, 두 하위 검색기의 요청 후보 수는 각각 10개였다. 결합은 청크 순위 기준이며 원점수는 합산하지 않는다.
- 각 요청에서 최대 10개 청크를 검색하고, 반환 순서에서 문서 ID의 첫 등장만 남겨 문서 Top-1·3·5·10을 평가했다. 중복으로 고유 문서가 10개 미만이면 그 수만 평가했다. 이전 실험의 문서 중복 제거 규칙을 사용했고, 청크 조회 한도는 이번에 10으로 고정했다. 이전 BM25 실험과 그때의 Dense·Hybrid 추가 비교는 50개 청크를 요청했다.
- HitRate는 후보 정답을 하나 이상 찾은 질문 비율이다. Recall은 질의별로 찾아낸 고유 정답 수를 해당 질문의 전체 정답 수로 나눠 평균한다. 이번에는 질문마다 후보 ID가 하나여서 두 지표가 같다. MRR@10은 첫 일치의 역순위를 평균하고, nDCG@5는 기존 모듈을 재사용했다.
- 모델 최초 로딩과 첫 임베딩, BM25 인덱스 생성은 별도로 기록했다. 검색기별 1회 워밍업 후 69개 질의를 3회 실행했다. 세 검색기 실행 순서를 질의와 반복마다 순환했고, 결과 캐시는 사용하지 않았다. 성능 지표는 첫 회 순위로, 지연시간은 세 회의 검색 요청 전체로 집계했다. Dense 시간은 임베딩과 Chroma 왕복을 포함하고, Hybrid 시간은 여기에 BM25와 RRF 결합을 포함한다. 이전 BM25 단독 수치는 인메모리 검색 시간이다.

Top-5에서 Dense가 놓친 네 질의는 Basic RRF가 모두 찾았고 Kiwi RRF는 세 개를 찾았다. Kiwi RRF는 Dense가 찾은 두 키워드 질의를 Top-5 밖으로 밀어냈다. 전체 세 방식 중 Basic RRF만 적중한 사례는 하나, Kiwi RRF만 적중한 사례와 모두 실패한 사례는 각각 0개였다. 후보 목록은 검색기의 실제 반환을 근거로 분석했다. 개별 토큰 또는 의미 유사성의 인과 효과는 분리 검증하지 않았다.

질문 텍스트, 후보 정답 문서 ID, 각 방식의 Top-5 문서 ID와 순위, 3회 검색 시간은 저장소 밖의 비공개 질문별 파일에 있다.

## 해석과 추천

향후 Hybrid 연동의 우선 검증 구성으로 **Dense + Basic BM25 RRF**를 추천한다. 원문 Top-5는 모두 25/25였고, Basic 결합은 원문 1위 적중을 23건에서 24건으로 늘렸다. 자동 변형 Top-5는 Dense 40/44, Basic 결합 44/44, Kiwi 결합 41/44였다. 개선은 짧은 키워드에 집중됐고, 어미 변경과 표현 치환에서는 세 방식 모두 1위에서 후보 문서를 찾았다.

Basic 결합은 평균과 p95 비용이 증가했다. 이번 환경에서 평균 증가는 작았으나 운영 트래픽과 응답시간 목표를 기준으로 수용 여부를 확인해야 한다. 현재 결과는 FAQ 원문과 규칙 기반 변형에 대한 탐색 평가다. 실제 고객 표현의 검수된 질의, 다중 정답 및 근거 없음 사례, 표면형이 겹치지 않는 의미 기반 질문에서 순위와 운영 지연을 재검증한다.

기존 RAG 단위 테스트 61개가 통과했다. 검색기 및 Runtime 코드와 Chroma 데이터는 기존 상태를 유지했다. [실험 스크립트](compare_live_hybrid.py)
